# Color Palette & Tokens Reference

### The 60-30-10 Design Matrix

```css
:root {
  /* 60% Canvas / Surfaces */
  --bg-paper: #FDFBF7;
  --bg-cream: #F5EFE3;
  --bg-white: #FFFFFF;

  /* 30% Dark Foundation */
  --ink-black: #111111;
  --charcoal: #1C1C1C;
  --text-primary: #141414;
  --text-secondary: #5C5A54;
  --text-muted: #A8A8A8;

  /* 10% Accents */
  --gold-primary: #A67C00;
  --gold-hover: #8A6500;
  --gold-light: #FAF3E3;
  --border-warm: #E8E0D0;

  /* System Actions */
  --whatsapp-green: #25D366;
}
```

### Industry Sub-Accents:
- **Salon / Spa**: Soft Taupe `#C9A68C` (Tag background: `#F8F2EE`)
- **Construction**: Safety Amber `#E8A800` (Tag background: `#FEF8E7`)
- **Dining**: Warm Gold `#A67C00` (Tag background: `#FAF3E3`)
- **Real Estate**: Deep Charcoal `#1C1C1C` / `#A67C00` (Tag background: `#FAF3E3`)
